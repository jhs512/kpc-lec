# KPC 금융 데이터 분석 강의 사이트

2026년 10월 6~8일, 3일·20시간 과정의 독립 정적 사이트입니다.

루트 일정 안내에서 교시별 수업 12개·단원 요약 7개·실습 준비 페이지로 이동합니다. 교시 자료는 쉬운 예시→용어→코드→직접 실습→결과 해석 순서로 읽습니다. 첫 환경 실습은 빈 폴더에서 시작하며 자료 ZIP은 Titanic을 시작하는 1일차 7교시에 받습니다.

## 개발과 배포

```sh
npm ci
npm test
npm run build
npm run serve
```

미리보기: http://127.0.0.1:4173/kpc-lec/

`main` push 후 GitHub Actions가 빌드하여 GitHub Pages에 배포합니다. `dist/`는 생성 파일입니다. 본문은 `content/`에서 수정합니다.

## 읽어주기

TOPCIT2의 문단별 한국어 음성 재생·일시정지·속도·문장 강조 코드를 재사용했습니다. 기기/브라우저의 Web Speech API 및 한국어 음성을 사용하며 서버 음성 서비스나 API 키를 사용하지 않습니다. 한국어 음성이 없으면 안내가 표시됩니다. 코드·표·탐색 메뉴는 낭독하지 않습니다.

## 공개 범위

교안과 사이트 코드·설명 그림, 이미 승인된 학생 ZIP만 포함합니다. 공식 PDF, 수강생 명단, 메일, 전체 원자료, 로컬 환경은 포함하지 않습니다. 자료 다운로드는 필요한 실습 페이지에서 제공하며 ZIP은 Notebook 12개·데이터 3개·환경 파일·사용 안내의 검증된 묶음입니다. 기존 Slog 글은 유지합니다.
