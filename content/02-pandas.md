# 요약

CSV·Excel을 pandas로 읽고 행·열 선택, 조건 필터링, 결측치 정리를 수행하며 BeautifulSoup 정적 웹 수집과 Selenium 네이버 검색 자동화의 흐름을 익힙니다.

## 수업 위치

1일차 · 3시간. 

## 학습 목표

CSV·Excel을 pandas로 읽고 행·열 선택, 조건 필터링, 결측치 정리를 수행하며 BeautifulSoup 정적 웹 수집과 Selenium 네이버 검색 자동화의 흐름을 익힙니다.

## 단원 목차



1. CSV, Excel 파일 읽기 및 pandas 기본 사용법
2. 행/열 선택 및 조건 필터링
3. 결측치 확인 및 기본 데이터 정리
4. BeautifulSoup을 활용한 정적 웹페이지 수집 실습
5. Selenium을 활용한 네이버 검색 자동화 실습

## 실습 방향

표를 읽어 조건에 맞는 행을 찾고 그룹별 통계를 계산합니다. 파일 예제는 직접 만든 표를 사용하므로 데이터 ZIP 없이 진행합니다.
