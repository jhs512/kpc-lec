## 1. 머신러닝 기본 개념: 지도학습, 분류/회귀 이해

## 2. 결측치 처리 및 불필요 컬럼 제거

이름·티켓 등의 식별 정보와 사고 후 정보를 입력에서 제외합니다. `boat`와 `body`를 넣으면 정답과 연결된 사후 정보가 모델에 들어가는 데이터 누수가 생길 수 있습니다. 결측치 통계만 살펴보고, 채울 값은 훈련 자료에서 정합니다.

```python
from pathlib import Path
import pandas as pd

titanic = pd.read_excel(Path("raw/기존강사 수업자료/titanic.xlsx"))
excluded = ["name", "ticket", "cabin", "boat", "body", "home.dest"]
model_data = titanic.drop(columns=excluded)
features = ["pclass", "sex", "age", "sibsp", "parch", "fare", "embarked"]
X = model_data[features].copy()
y = model_data["survived"].astype(int)
print("입력:", X.shape, "정답:", y.shape)
print(X.isna().sum())
```

입력은 1,309행·7열입니다. 결측 age 263개, fare 1개, embarked 2개를 이후 Pipeline 안에서 처리합니다. 이 코드에서는 원본 파일을 수정하지 않습니다.

## 3. 범주형 데이터 인코딩 및 데이터 정제

문자열 범주를 숫자 열로 변환하는 One-hot encoding을 사용합니다. 범주형 결측은 최빈값, 숫자 결측은 중앙값으로 채웁니다. Logistic Regression을 위해 숫자 열의 크기도 표준화합니다. 아래 함수는 처리 절차를 정의하며 아직 자료에 `fit`하지 않습니다.

```python
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import OneHotEncoder, StandardScaler

numeric = ["pclass", "age", "sibsp", "parch", "fare"]
categorical = ["sex", "embarked"]

def make_preprocessor():
    return ColumnTransformer([
        ("numeric", Pipeline([
            ("impute", SimpleImputer(strategy="median")),
            ("scale", StandardScaler()),
        ]), numeric),
        ("category", Pipeline([
            ("impute", SimpleImputer(strategy="most_frequent")),
            ("encode", OneHotEncoder(handle_unknown="ignore")),
        ]), categorical),
    ])
```

`handle_unknown="ignore"`는 테스트 때 훈련 자료에 없던 범주가 나와도 오류로 멈추지 않도록 합니다. 중앙값·최빈값·인코딩 범주는 Pipeline이 `fit`할 때 훈련 자료에서만 정해집니다. [scikit-learn 공식 누수 방지 안내](https://scikit-learn.org/stable/common_pitfalls.html)를 따릅니다.

## 4. train/test 분리

```python
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42,
)
print("훈련:", X_train.shape, "테스트:", X_test.shape)
print("훈련 생존율:", round(y_train.mean(), 4))
print("테스트 생존율:", round(y_test.mean(), 4))
assert set(X_train.index).isdisjoint(X_test.index)
```

훈련 1,047명, 테스트 262명입니다. `stratify=y`는 두 묶음의 정답 비율을 비슷하게 유지하고 `random_state`는 분리 결과를 재현하기 위한 값입니다. 테스트 결과를 보며 계속 설정을 바꾸면 테스트도 개발에 쓰게 되므로, 정식 튜닝에는 별도의 검증 자료가 필요합니다.

## 직접 해보기와 정답

아래 셀로 전처리 함수가 무엇을 하는지 관찰합니다. 이것은 전처리 확인용이고, 6교시 모델은 각자 새 전처리 함수를 Pipeline으로 만듭니다.

```python
prepared = make_preprocessor()
train_array = prepared.fit_transform(X_train)
test_array = prepared.transform(X_test)
print("원래 훈련 입력:", X_train.shape)
print("변환 후 훈련 입력:", train_array.shape)
print("변환 후 테스트 입력:", test_array.shape)
print(prepared.get_feature_names_out())
```

## 흔한 오류와 해결

| 증상 | 해결 |

| ModuleNotFoundError: sklearn | 현재 Notebook Kernel에 scikit-learn을 설치하고 Kernel을 재시작합니다. 패키지 이름은 scikit-learn, import 이름은 sklearn입니다. |
| 문자열을 float으로 바꿀 수 없다는 오류 | 문자열 열을 직접 모델에 넣지 않고 범주형 인코딩 Pipeline을 사용합니다. |
