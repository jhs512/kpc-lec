## 4. BeautifulSoup을 활용한 정적 웹페이지 수집 실습

BeautifulSoup은 이미 받은 HTML을 읽어 원하는 요소를 찾습니다. JavaScript로 나중에 만들어지는 화면을 직접 실행하지 않습니다. 먼저 통신 없이 실행되는 작은 HTML로 선택자와 표 변환을 익힙니다.

```python
from bs4 import BeautifulSoup

html = """<html><body><ul id="prices">
<li data-code="A"><span class="name">가상A</span><b>10,000</b></li>
<li data-code="B"><span class="name">가상B</span><b>20,000</b></li>
</ul></body></html>"""
html_file = work / "prices.html"
html_file.write_text(html, encoding="utf-8")
soup = BeautifulSoup(html_file.read_text(encoding="utf-8"), "html.parser")
rows = []
for item in soup.select("#prices li"):
    rows.append({
        "code": item["data-code"],
        "name": item.select_one(".name").get_text(strip=True),
        "price": int(item.select_one("b").get_text(strip=True).replace(",", "")),
    })
web_df = pd.DataFrame(rows)
web_df.to_csv(work / "web_prices.csv", index=False, encoding="utf-8-sig")
print(web_df.to_string(index=False))
```

2행·3열의 표가 만들어집니다. HTML에서 텍스트를 뽑은 다음 쉼표를 제거해 숫자로 바꿨습니다. 실제 정적 URL을 사용할 때는 HTTP 요청의 성공 여부와 문자인코딩을 확인한 뒤 같은 파싱 과정을 적용합니다. 빈 선택 결과는 가격 0을 뜻하지 않습니다.

**직접 실습:** HTML에 가상C·15,000을 추가해 3행이 만들어지는지 확인합니다. 선택자를 `#prices .name`으로 바꾸면 어떤 요소를 얻는지 비교합니다. 자세한 선택자 문법은 [BeautifulSoup 공식 문서](https://www.crummy.com/software/BeautifulSoup/bs4/doc/)를 참고합니다.

## 5. Selenium을 활용한 네이버 검색 자동화 실습

Selenium 네이버 검색 자동화는 강사 시연과 직접 실행으로 다룹니다. 정적 HTML·URL 생성은 접속 실패 때도 원리를 확인하기 위한 보조 실습입니다. Selenium은 브라우저를 실행해 페이지를 이동하고 입력·클릭을 수행합니다. 여기서는 네이버 검색창에 검색어를 넣고 Enter를 누릅니다. 페이지가 준비될 때까지 명시적으로 기다립니다. Chrome 설치와 드라이버 다운로드가 가능한 네트워크가 필요합니다.

```python
# 이 셀은 브라우저를 실제로 실행하는 현장 실습입니다.
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.common.keys import Keys
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

query = "금융 데이터 분석"
driver = webdriver.Chrome()
try:
    driver.get("https://www.naver.com/")
    wait = WebDriverWait(driver, 15)
    search_box = wait.until(EC.element_to_be_clickable((By.NAME, "query")))
    search_box.send_keys(query)
    search_box.send_keys(Keys.ENTER)
    wait.until(EC.url_contains("search.naver.com"))
    print("검색 결과 URL:", driver.current_url)
    print("페이지 제목:", driver.title)
finally:
    driver.quit()
```

확인할 결과는 검색 결과 주소와 입력한 검색어입니다. 네이버의 화면 구조·접속 상황에 따라 결과와 대기 시간이 달라집니다. `TimeoutException`이면 먼저 직접 접속해 화면이 뜨는지 확인하고, 검색 입력 요소의 이름이 여전히 `query`인지 확인합니다. 브라우저·네이버 실제 동작은 수업 환경에서 최종 점검합니다. 정적 HTML 파싱과 URL 생성은 별도로 검증했습니다. [Selenium 대기 공식 문서](https://www.selenium.dev/documentation/webdriver/waits/)에 설명된 명시적 대기를 사용합니다.

입력 요소를 찾는 실습이 막히면 검색 주소를 만드는 원리를 먼저 확인할 수 있습니다. 아래 코드는 브라우저를 실행하지 않습니다.

```python
from urllib.parse import urlencode, urlparse, parse_qs
query = "금융 데이터 분석"
search_url = "https://search.naver.com/search.naver?" + urlencode({"query": query})
print(search_url)
print(parse_qs(urlparse(search_url).query)["query"][0])
```

**직접 실습:** 검색어를 `pandas DataFrame`으로 바꾸고 결과 URL의 검색어를 확인합니다. 파일로 수집한 표와 브라우저 검색 화면의 차이를 한 문장으로 설명합니다.

## HTML 선택자 읽기

예제의 `<ul id="prices">`는 목록 전체이고 `<li data-code="A">`는 한 종목입니다. `<span class="name">`에 이름이, `<b>`에 가격 문자열이 들어 있습니다.

| 선택자 | 선택 대상 |
| --- | --- |
| `#prices` | id가 prices인 요소 |
| `#prices li` | 그 요소 내부의 li 요소들 |
| `.name` | class가 name인 요소 |
| `b` | b 태그 요소 |

`select()`는 일치하는 요소의 목록, `select_one()`은 첫 요소 하나를 반환합니다. 먼저 행 단위 `li`를 고른 뒤 각 행 내부에서 이름·가격을 찾으면 다른 종목의 값이 섞이지 않습니다. `get_text(strip=True)`는 태그 안의 텍스트를 꺼내 주변 공백을 정리합니다. `"10,000"`은 문자열이므로 쉼표를 제거하고 `int()`로 바꿔야 덧셈·비교에 쓸 수 있습니다.

## 직접 실습 — 검색어와 URL

Selenium 예제에서 검색어를 `pandas DataFrame`으로 바꿉니다. 검색 결과 URL을 출력한 뒤 그 주소의 query 항목에 검색어가 담겼는지 확인하세요. Chrome이 열리지 않는 PC에서는 본문 URL 생성 예제를 실행하여 같은 검색어가 들어 있는지 확인하되, 이 결과만으로 브라우저 자동화에 성공했다고 기록하지 않습니다.

<details>
<summary>정답과 확인 원리</summary>

Selenium 실행 코드의 `query = "금융 데이터 분석"`을 `query = "pandas DataFrame"`으로 바꾸고 전체 셀을 다시 실행합니다. 네이버 화면과 주소가 바뀔 수 있으므로 고정된 페이지 제목을 정답으로 삼지 않습니다.

브라우저 없이 주소를 확인하는 코드는 다음과 같습니다.

```python
from urllib.parse import urlencode, urlparse, parse_qs

query = "pandas DataFrame"
search_url = "https://search.naver.com/search.naver?" + urlencode({"query": query})
decoded_query = parse_qs(urlparse(search_url).query)["query"][0]
print(decoded_query)
print(decoded_query == query)
```

출력은 `pandas DataFrame`, `True`입니다. 한글이나 공백이 주소에서는 인코딩되어 보여도 복원한 값이 원래 검색어와 같으면 됩니다.

</details>

## 흔한 오류와 복구

| 오류·현상 | 확인과 해결 |
| --- | --- |
| `ModuleNotFoundError: bs4` | 패키지 설치 이름은 beautifulsoup4, import 이름은 bs4입니다. 수업 환경에 설치합니다. |
| 선택 결과가 비어 있음 | 선택자와 HTML 구조를 확인합니다. 빈 목록을 가격 0으로 바꾸지 않습니다. |
| `AttributeError`와 None 표시 | `select_one()`이 찾지 못했습니다. 실제 HTML에 해당 요소가 있는지 확인합니다. |
| `ValueError`로 가격 변환 실패 | 쉼표·통화기호·공백 등 문자열 형식을 먼저 확인합니다. 오류 값을 임의로 0으로 바꾸지 않습니다. |
| Chrome 드라이버 준비 실패 | Chrome 설치와 네트워크·드라이버 다운로드 접근을 확인합니다. |
| `TimeoutException` | 직접 네이버가 열리는지, 검색 요소 이름이 query인지 확인합니다. 대기 조건을 실제 화면에 맞춰야 합니다. |
| 브라우저가 바로 닫힘 | 예제는 `finally: driver.quit()`로 자원을 정리합니다. 출력된 URL·제목으로 실행 결과를 확인합니다. |

## Windows·Mac의 Chrome과 드라이버

Chrome은 [공식 설치 안내](https://support.google.com/chrome/answer/95346?hl=en)를 따릅니다. Mac은 `.dmg`를 열고 Chrome을 Applications에 옮깁니다. 현재 공식 Chrome의 Mac 요구사항은 macOS 13 이상이므로 버전을 확인합니다.

예제의 `webdriver.Chrome()`은 두 OS에서 같습니다. 별도 드라이버 경로를 지정하지 않으면 Selenium Manager가 OS·아키텍처와 Chrome 버전에 맞는 드라이버를 준비합니다. 최초 다운로드에는 네트워크 연결이 필요할 수 있습니다. Windows의 `chromedriver.exe` 경로를 Mac에 복사하지 않습니다. [Selenium Manager 공식 문서](https://www.selenium.dev/documentation/selenium_manager/)

브라우저 시작 오류라면 Chrome 설치·업데이트, 다운로드 네트워크, 선택 Kernel의 Selenium 설치를 차례로 확인합니다. 회사 네트워크에서 드라이버 다운로드가 차단되면 정적 HTML 실습을 먼저 진행하고 강사와 환경을 확인합니다. 예제의 `finally: driver.quit()`으로 브라우저 세션을 종료합니다.
