# 요약

지도학습과 분류·회귀를 이해하고 결측치·컬럼·범주형 데이터를 정리한 뒤 train/test를 분리하여 Logistic Regression·Decision Tree·RandomForest를 학습합니다.

## 수업 위치

2일차 · 3시간. 

## 학습 목표

지도학습과 분류·회귀를 이해하고 결측치·컬럼·범주형 데이터를 정리한 뒤 train/test를 분리하여 Logistic Regression·Decision Tree·RandomForest를 학습합니다.

## 단원 목차



1. 머신러닝 기본 개념: 지도학습, 분류/회귀 이해
2. 결측치 처리 및 불필요 컬럼 제거
3. 범주형 데이터 인코딩 및 데이터 정제
4. train/test 분리
5. Logistic Regression, Decision Tree, RandomForest 모델 학습

## 실습 방향

Titanic 생존 분류 모델을 학습하고 학습/테스트 결과와 혼동행렬을 비교합니다.
